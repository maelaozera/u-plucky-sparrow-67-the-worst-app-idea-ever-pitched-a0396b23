Entry for the [make.fun](https://make.fun) competition
[The Worst App Idea Ever Pitched](https://make.fun/c/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23).

**PingPong** is the app that lets you send a push notification to your own
phone from your own phone, complete with a satisfying ping, so you never miss
an urgent message from yourself again.

Running `node main.ts` writes that one sentence (187 characters, no trailing
newline) to `/output/entry.txt`. No dependencies, no network, fully
deterministic.
